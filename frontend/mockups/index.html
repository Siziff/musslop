musslop — варианты дизайна UI

Статические мокапы без функционала. Открой каждый, сравни, выбери направление.

1 · Light Studio

Светлый профессиональный DAW-стиль: чистый, спокойный, «инструмент для работы». Inter, мягкие тени, синий+зелёный акценты.

2 · Fantasy Tavern

D&D-атмосфера: тёмное дерево, пергамент, золото, засечки IM Fell. Части трека — «локации»: Таверна, Лес, Подземелье.

3 · Neon Synthwave

Киберпанк/ретровейв: неоновое свечение, сетка на фоне, Orbitron, розовый+бирюза. Максимально «гиковый» вайб.

4 · Minimal Mono

Бруталистский монохром: почти ч/б, один лаймовый акцент, прямые углы, Space Mono. Терминальная эстетика, ничего лишнего.
