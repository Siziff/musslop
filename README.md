# musslop

Адаптивные игровые лупы из любого трека — как в геймдев-саундтреках:
части трека зацикливаются бесконечно, а по кнопке «Дальше» текущий луп
доигрывает до своей границы и бесшовно переходит к следующей части.

## Как это работает

**Автоматическая нарезка** (backend, `librosa`):

1. **Beat tracking** — огибающая онсетов + динамическое программирование (Ellis, 2007): темп и позиции битов.
2. **Downbeats (такты)** — предполагается размер 4/4; фаза сильной доли выбирается как сдвиг, максимизирующий силу онсетов на каждом 4-м бите.
3. **Структурная сегментация** (Foote, 2000) — beat-синхронные признаки (CQT-хрома для гармонии + MFCC для тембра) → матрица самоподобия → свёртка «шахматным» ядром по диагонали → кривая новизны → пики = границы секций (интро/куплет/припев/бридж…).
4. **Музыкальное квантование** — границы притягиваются к ближайшему downbeat; секции не короче 2–4 тактов (музыкальная фраза).

**Воспроизведение** (frontend, Web Audio API): каждый проход лупа планируется
отдельным `AudioBufferSourceNode` с sample-точным стартом; микро-фейды (6 мс)
убирают щелчки. По кнопке «Дальше» следующий запланированный кусок берётся из
следующей части — переход происходит ровно на границе лупа, без разрыва.

## Запуск

```bash
pip install -r requirements.txt   # требуется также ffmpeg в PATH
uvicorn backend.main:app --host 0.0.0.0 --port 8765
```

Открыть http://localhost:8765

## UI

- Переключение языка интерфейса: RU / EN (запоминается в localStorage)
- Загрузка трека (drag&drop): mp3, wav, ogg, flac, m4a…
- Waveform с сегментами, битами (короткие штрихи) и тактами (длинные штрихи)
- Редактирование: перетаскивание границ мышью (с привязкой к тактам), двойной клик — разрезать часть, «✕» — слить с предыдущей, переименование частей
- «Переанализировать» с заданным числом частей
- Горячие клавиши: `Пробел` — играть/стоп, `→`/`Enter` — «Дальше»

## Структура

```
backend/

  analysis.py   # beat tracking, downbeats, novelty-сегментация
frontend/
  index.html    # React (CDN) + Web Audio плеер и редактор
```
